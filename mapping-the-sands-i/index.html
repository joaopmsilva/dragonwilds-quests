Mapping The Sands I is a secondary quest within the Umbral Sands region of Ashenfall.

Overview

Description
Discover Moon Sprites on top of tall locations around the Alcarrid Camp to map the Umbral Sands.
Start Point
Speak to the Anamcara in Umbral Sands
Type
Secondary Quest
Requirements
Partial completion of Icthlarin's Little Helper
Required items
None
Recommended items
None
Enemies to defeat
None

Walkthrough

Speak to Moon Sprite Shaman - Anamcara in Umbral Sands to start this quest. Anamcara is located in Alcarrid Camp, next to pond.

Rewards

  • Blue desert cape

Required to Start

  • Mapping The Sands II
